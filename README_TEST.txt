JJB MOUTIERS - VERSION TEST V2.1

Cette version est responsive : le MEME site fonctionne sur ordinateur, tablette et smartphone.

ORDINATEUR
1. Decompresser le ZIP.
2. Double-cliquer sur index.html.
3. Ouvrir avec Chrome, Edge, Firefox ou Safari.

SMARTPHONE
Le site est le meme : il s adapte automatiquement a la largeur de l ecran.
Pour un test local, transferer le dossier complet sur le telephone puis ouvrir index.html depuis l application Fichiers.
Selon le telephone, l ouverture des widgets HelloAsso dans un fichier local peut etre limitee par le navigateur. Ils fonctionneront normalement des que le site sera mis en ligne.
