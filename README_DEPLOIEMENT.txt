JJB MOUTIERS - V2.3 TEST
========================

Cette version est prête pour une mise en ligne de test sur Vercel.

IMPORTANT :
- La version de test demande aux moteurs de recherche de NE PAS indexer le site.
- Une fois le nom de domaine définitif connecté, retirer :
  1) <meta name="robots" content="noindex,nofollow"> dans index.html
  2) robots.txt (ou le remplacer par Allow: /)
  3) l'en-tête X-Robots-Tag dans vercel.json
- Renseigner ensuite l'URL définitive dans les balises Open Graph/canonical.

Les deux widgets HelloAsso sont intégrés, avec des liens de secours directs.
Le site est responsive ordinateur + tablette + smartphone.
